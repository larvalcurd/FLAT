# Список тестов

## Итерация 1: Лексер

### 1. Набор допустимых символов (п. 2.1)
- [x] Ошибка: недопустимые символы вне строк и комментариев: `!`, NUL, 0xFF
- [x] Позиция ошибки на следующей строке
- [x] Ошибка: `/` вне `//`: `a/b`
- [x] Ошибка: `}` вне комментария: `a } b`

### 2. Идентификаторы (п. 2.2)
- [x] Разбор идентификаторов из латинских букв, цифр и `_`: `a`, `a1`, `a_b`, `_a`
- [x] Регистронезависимость, приведение к нижнему регистру: `ABC` → `abc`
- [x] Разбор идентификаторов, содержащих ключевое слово: `begin1`, `writelnx`
- [x] Ошибка: идентификатор начинается с цифры: `1a`
- [x] Ошибка: не-ASCII буква в идентификаторе: `абв`

### 3. Ключевые слова (п. 2.3)
- [x] Разбор ключевых слов: program, var, const, procedure, function, integer, boolean, string, record, array, of,
begin, end, if, then, else, while, do, write, writeln, read, readln, true, false, and, or, not, div, mod
- [x] Разбор ключевых слов в любом регистре: `PROGRAM`, `Begin`, `WriteLn`

### 4. Целые литералы (п. 2.4)
- [x] Разбор целочисленных литералов: `0`, `123`
- [x] Разбор литералов вне диапазона int (проверка диапазона - в семантике): `2147483648`
- [x] Знак - отдельная лексема: `-1`
- [x] Разбор вещественной записи как трёх лексем: `1.2`
- [x] Ошибка. ведущий ноль: `01`
- [x] Ошибка. `_` сразу после цифр: `1_`

### 5. Булевы литералы (п. 2.5)
- [x] Разбор булевых литералов: `true`, `false`
- [x] Разбор булевых литералов в любом регистре: `TRUE`, `False`

### 6. Строковые литералы (п. 2.6)
- [x] Разбор строковых литералов: `''`, `'abc'`
- [x] Сохранение регистра в строках: `'aBc'`
- [x] Спецсимволы внутри строки не имеют значения: `'{}'`, `'//'`
- [x] Разрешены табуляция, символы 0x80–0xFF и кириллица: `'a\tb'`, `'ÿ'`, `'абв'`
- [x] Ошибка. Запрещённый управляющий символ: 0x00, 0x0C, 0x7F
- [x] Поддержка удвоенной кавычки: `'a''b'`, `''''` (п. 2.6.1)
- [x] Ошибка. Перевод строки внутри строки: LF, CR (п. 2.6.2)
- [x] Ошибка. Незакрытая строка: `'a`, `'a''` (п. 2.6.2)

### 7. Операторы (п. 2.7)
- [x] Оператор сложения: \+
- [x] Оператор вычитания: \-
- [x] Оператор умножения: \*
- [x] Буквенные операторы: div, mod, and, or, not
- [x] Оператор равно: =
- [x] Оператор не равно: <>
- [x] Оператор меньше: <
- [x] Оператор меньше или равно: <=
- [x] Оператор больше: \>
- [x] Оператор больше или равно: \>=
- [x] Оператор присваивания: :=
- [x] Выбор самой длинной лексемы: `:==`, `<>=`
- [x] Составной оператор, разделённый пробелом - две лексемы: `: =`

### 8. Разделители и специальные символы (п. 2.8, 2.9)
- [x] Разбор скобок: ( ), [ ]
- [x] Разбор разделителей: , : ; . ..
- [x] Точка и диапазон - разные лексемы: `...` → `..` и `.`
- [x] `(* *)` - не комментарий
- [x] Разбор объявления массива: `a:array[1..10]of integer;`
- [x] Разбор объявления константы: `const a = 1;`
- [x] Разбор вывода: `writeln('a');`

### 9. Комментарии (п. 2.10)
- [x] Разбор однострочных комментариев: до LF, CR и конца файла
- [x] Разбор многострочных комментариев с табуляцией и переводами строк внутри
- [x] Комментарий закрывается первой `}`: `{a{b}c`
- [x] Ошибка. Вложенный комментарий оставляет лишнюю `}`
- [x] Ошибка. Незакрытый многострочный комментарий
- [x] Спецсимволы и кириллица внутри комментариев: `'`, `{`, `}`, `//`, `абв`
- [x] Ошибка. Запрещённый управляющий символ в `//` и в `{ }`
- [x] Комментарий разделяет лексемы: `a{}b`

### 10. Пробельные символы (п. 2.11)
- [x] Пустой вход и вход только из пробелов (SP, HT, LF, CR, FF, CRLF) дают EOF
- [x] Подсчёт строк: LF, CR, CRLF - один перевод строки
- [x] Позиции всех токенов в многострочном тексте, включая EOF

### 11. Лексические ошибки (п. 2.12)
- [x] Токены до ошибки выдаются, ошибка - на своей позиции
- [x] Повторный вызов после EOF возвращает EOF

### 12. Сквозной тест
